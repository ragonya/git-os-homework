## Моё объяснение

[Инструменты `amend` и интерактивный `rebase` предназначены для локальной очистки истории перед отправкой кода:
- Команда `git commit --amend` позволяет быстро исправить опечатку в сообщении самого последнего коммита.
- Команда `git rebase -i` открывает текстовый план, где разработчик может управлять старыми коммитами. Инструкция `reword` позволяет точечно менять сообщения старых коммитов. Инструкция `squash` склеивает коммит с предыдущим, объединяя их код и открывая редактор для создания общего сообщения.]

Ожидаемый ответ: amend меняет SHA последнего коммита; `reword` меняет сообщение; `squash` объединяет два коммита; в результате три содержательных коммита.
