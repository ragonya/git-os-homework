## Моё объяснение

[В Git существуют разные способы отмены изменений в зависимости от того, были ли они уже отправлены в общий репозиторий:
- Команда `git revert` используется для безопасной отмены уже опубликованных коммитов. Она не удаляет коммит из истории проекта, а создает новый коммит с корректными изменениями.
- Команда `git restore` позволяет извлечь состояние конкретного файла из любого прошлого коммита и заменить им текущую версию на диске.]

Ожидаемый ответ: revert создаёт новый коммит для отмены коммита; для одного файла используется restore.
