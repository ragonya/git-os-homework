## Моё объяснение

`[.gitignore действует только на неотслеживаемые файлы: он не даёт случайно добавить их в git. Если файл уже был закоммичен, git продолжает его отслеживать несмотря на правила. Чтобы перестать отслеживать такой файл, нужен git rm --cached: он удаляет файл из индекса (не с диска), после коммита начинает работать правило из .gitignore. В старых коммитах файл остаётся.]`

Ожидаемый ответ: .gitignore не перестаёт отслеживать уже tracked-файл; `git rm --cached` убирает файл из индекса, сохраняя его на диске.
