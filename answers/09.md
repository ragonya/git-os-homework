## Моё объяснение

`[git reset --hard HEAD~1 переносит ветку на коммит назад, и LOST пропадает из истории, но сам коммит из репозитория не удаляется. Git записывает каждое перемещение HEAD в reflog, поэтому по нему можно найти SHA потерянного коммита и вернуть на него ветку через git reset --hard <SHA>. Reflog локальный и на GitHub не отправляется, поэтому так можно спасти только то, что делалось локально.]`

Ожидаемый ответ: reflog хранит локальные движения ссылок и позволяет найти потерянный коммит.
